# Coursework Study：适用于学习通等教学平台的作业自动化与学习资料 Skill

让 AI Agent 按题目要求完成作业，验证、提交并核实结果，再把这次作业整理成可复习的 PDF。

这是一套可迁移的 **Agent Skill**。它为具备浏览器或桌面控制、代码运行和文档生成能力的 AI Agent 提供执行流程，覆盖“进入课程 → 读取题目 → 分析作答 → 验证 → 读回核对 → 提交 → 核实结果 → 生成学习资料”。已在学习通的 C 语言和线性代数作业场景中实践；其他教学网站在首次使用时逐个适配。

> 作业交了，知识点也留下了。自动整理的学习 PDF，多少减轻一点“交完就忘”的负罪感——当然，资料还得自己看，练习还得自己做。

## 能做什么

- **按题目处理多种交付形式**：选择、填空、计算证明、C 语言编程、代码流程图、实际运行截图和附件提交。
- **验证后提交**：编程题可使用现有编译器或平台评测；写入后读回答案，提交前逐题核对实际选项、最终代码及附件预览。
- **依据反馈修正**：平台允许重做且存在可解释的修正依据时，以满分为目标持续修正；待批阅按已提交完成处理，准确报告状态。
- **自动产出学习 PDF**：根据本次真实作业整理知识点、推导、代码、验证结果、易错点和巩固练习；支持明确指定“无需学习资料”。
- **复用已有登录会话**：由浏览器管理会话，启动后现场检查；遇到需要人工处理的登录或验证时保留进度。
- **支持多种 Agent**：核心说明采用 Markdown 和相对文件引用，工具名称、操作系统及连接器不作为通用前提。
- **控制上下文开销**：按需加载说明，优先文字和控件读取、必要时局部截图；批量任务用精简状态记录恢复，保留关键核对步骤。

## 与固定流程自动脚本有什么不同

以下比较的是两种实现方式，不代表对所有学习通脚本做过横向测评；具体项目可能同时具备其中多项能力。

| 比较点 | 以固定流程为主的脚本 | 本 Skill 的设计 |
|---|---|---|
| 执行方式 | 预先编写接口调用、选择器或点击步骤 | Agent 读取当前题目和页面，选择可用工具执行 |
| 题目变化 | 依赖脚本已经实现的题型与规则 | 结合模型分析与实际验证处理，能力受模型和工具限制 |
| 平台适配 | 维护平台专用代码 | 核心流程通用，新网站现场适配并按需积累说明 |
| 提交内容 | 取决于脚本是否实现对应交付 | 题目可以要求代码、图片、流程图或文件，按要求制作核实 |
| 结果判断 | 常依赖预设成功条件 | 区分运行通过、提交成功、待批阅与实际成绩 |
| 作业后的产出 | 取决于项目功能 | 默认整理对应知识点和学习 PDF，支持关闭 |
| 成本与速度 | 稳定、简单的重复任务通常更有优势 | 需要模型推理和工具调用，复杂题型更灵活，但可能较慢且消耗 token |

## 开始使用

本仓库根目录就是 Skill 目录，入口为 [SKILL.md](SKILL.md)。它不包含独立运行的自动答题程序、内置模型、题库或浏览器控制器，也不会自行获得账户访问权限。

1. 下载本仓库，保留 `SKILL.md`、`references/` 和 `agents/` 的相对结构。
2. 支持 Skill 的 Agent：将整个目录命名为 `coursework-study`，放入该工具的技能目录；具体路径遵循所用工具的机制。
3. 其他 Agent：把 `SKILL.md` 作为自定义指令入口，并允许读取所需的 `references/` 文件。
4. 按 [运行环境配置](references/local-config.md) 确认浏览器、工作目录和已有工具能力，然后指定平台、课程与作业范围。

示例请求：

```text
使用 coursework-study，完成学习通中 C 语言程序设计课程的全部未提交作业，
提交后核实成绩，并生成对应的 PDF 学习资料。
```

```text
读取 coursework-study/SKILL.md 及需要的引用文件，
完成我指定网站中的线性代数作业，无需学习资料。
```

用户要求“完成”包含核对后提交；仅查看、分析或试运行时，按实际请求范围执行。

## 自动化的实际边界

“全自动”取决于当前 Agent 的工具、网站状态和题目要求，不保证所有网站、所有题型都能无人干预完成，也不保证满分。

- 已有学习通适配经验；其他网站需要首次适配，网站更新也可能需要调整。
- 真实手绘照片、实物或实验素材需要对应真实材料；缺失时先完成其他可处理任务，再报告剩余材料。
- 没有浏览器控制能力时，可以分析题目和制作文件，但无法完成网页提交。
- 无重做入口、反馈不足或重复失败且没有新依据时，报告成绩与剩余问题。
- PDF 需要当前环境提供可用的文档生成能力，并检查中文、代码、图示及分页。

## 反馈修正与凭据处理

不通过盲目枚举答案刷分；修正必须依据题目分析、测试或平台反馈。允许重做且具备新依据时持续修正，以满分为目标；待批阅按已完成处理，无法继续时如实报告。

密码、Cookie、登录令牌由浏览器或运行环境管理，不写入 Skill、脚本、日志、PDF 或可分享文件。公开仓库只包含通用指令，不包含个人作业、学生信息、运行截图及登录状态。

