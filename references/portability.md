# 工具与移植

## 能力映射

| 工作 | 可使用的现有能力 |
|---|---|
| 网站读取与交互 | 优先使用可用且已验证的 Playwright MCP；其次为其他浏览器工具、桌面控制与截图 |
| 程序验证 | 指定 IDE、现有本地编译器或平台在线评测 |
| 流程图 | SVG 或现有绘图工具，导出题目接受的图片 |
| 结果核实 | 页面文字、附件预览、实际截图及评测结果 |

优先使用当前环境可靠且能满足要求的工具。不要把工具名称、Windows 路径、鼠标坐标或某个连接器当作通用前提。没有浏览器控制能力的 Agent 可以分析用户提供的题目并制作答案或提交附件，但应说明无法完成网站提交。依赖安装遵循用户及运行环境的要求。

## Playwright MCP 网页操作

使用当前环境实际暴露的工具及参数，不假定所有部署提供相同工具。Playwright MCP 是优先选项，不是安装前提；缺失时继续使用可用工具，不自动安装服务器、扩展或浏览器。

1. **确认连接对象**：检查标签页、网址、课程和作业标题，确认当前会话属于用户指定目标。需要复用已有登录时，使用环境已配置的现有浏览器连接方式；独立浏览器上下文不一定继承登录状态。连接失败先检查目标与会话，登录或安全验证需本人操作时保留进度并说明。
2. **读取当前页面**：优先使用结构化快照读取题干、按钮和控件状态，以角色、名称、标签或当前快照引用定位。出现重复名称时限定到相应题号或区域，操作前确认唯一目标；导航或页面重建后重新获取引用。快照缺少图片、公式或编辑器内容时，补充截图或工具支持的页面读取，不将缺失内容当作空题。
3. **验证作答能力**：在本次已授权作答的第一道目标题目输入实际答案并读回；编程题还需运行并检查反馈是否对应当前代码。不为测试修改已完成作业，不输入无关占位内容，也不以提交作为连接测试。确认可可靠操作后再处理其余同类题目。
4. **处理特殊控件**：编辑器或题目位于嵌入页面时，使用工具支持的相应页面或框架定位；代码读回必须覆盖完整内容。常规输入失败先检查焦点、只读状态和实际控件，再使用工具支持的键盘输入方式。仍不能可靠输入或读回时，改用已验证的桌面工具；无法验证则保留进度并报告，不直接修改页面内部状态伪造作答。
5. **等待与核实**：点击后等待对应页面、控件状态或结果文字出现，再读取新状态。超时只表示尚未观察到目标状态，不证明操作失败；提交后按作答核对中的恢复分支处理。工具调用成功不替代答案读回、运行验证、附件预览或提交结果核实。

只返回当前题目和必要状态，避免每次将整页快照送入上下文；工具不支持局部读取时，确保完整读取所需信息后再继续。图片、公式及附件视觉质量保留截图核验。

## 新网站适配记录

首次遇到新网站时，在现有私有任务记录中按需保留以下内容，后续使用前核对当前页面是否仍适用；简单任务不另建记录系统。

`平台及正常入口 | 验证日期 | 课程/作业入口 | 题型与编辑器 | 已验证的输入及读回方式 | 附件限制 | 提交确认 | 结果与重做入口 | 未验证项/阻塞`

只将实际成功的步骤标为已验证；提交状态不明时，结果核实方式仍记为未验证。采用可读的导航路径及控件含义，不保存固定坐标、答案、学生信息、Cookie、令牌或带签名链接。任务进度中的答案仍按作答核对保存在私有记录，不能混入通用适配说明。

用户授权更新 Skill 后，将脱敏且已验证的差异写入对应平台引用，并在入口中说明何时读取；不将平台特例扩展为所有网站的规则。尚未实测的平台不预建“已适配”说明。

## 读取与 token 开销

- 优先读取当前题干、控件值、选中状态和结果文字；图片、公式、布局及附件视觉质量用截图核实。首次适配可观察全屏，后续优先截包含题号和必要上下文的局部区域；若工具不支持可靠的文字读取或局部截图，使用现有截图能力，不为省 token 盲操作。
- 首次完整读取作业要求后保留原文或附件在私有工作目录，向模型返回当前所需题目及格式要求。后续按题号读取，页面变化时补读变化部分。不要先返回整页长文再总结，或反复返回同一张截图。
- 在工具侧筛选无关浮层、重复导航、长日志和成功用例明细，返回失败项及必要上下文；不截断题干、选项、输出字符串或关键报错。读取范围不足时主动扩展。
- 独立读取和计算可以合并；只有已确认位置稳定的交互才批量执行。导航、滚动、弹窗后的重新观察，以及输入后读回、最终逐题核对和提交结果核实照常执行。
- 优先复用当前环境已验证的窗口激活、输入、读取及截图助手。只有重复操作确实值得封装时才编写小脚本，路径和目标可配置，不写死页面坐标或保存凭据。迁移时按当前工具能力替换，不为此增加通用框架或安装依赖。
- 遇到错误先按现有证据定向检查：输入异常读回控件，格式错误比较输出字符串，上传异常查附件，结果不明查提交状态。仅在局部证据不足时扩大检查，避免每次从头读取整个课程。

## 桌面操作稳定性

优先使用能定位目标页面和控件的浏览器工具；需要桌面鼠标键盘操作时，执行以下规则：

- 连续控制桌面前，简短提示用户暂时不要操作鼠标键盘；无需等待用户确认才开始。
- 每组点击或输入前，在同一次工具执行中激活目标窗口并核实当前页面及输入位置。不能假定上一轮操作后窗口仍在前台。
- 页面标题会随标签页切换而变化。按当前窗口信息定位；标题匹配失败时重新发现窗口，不向未知前台窗口继续发送按键。
- 只批量执行目标已确认且不会因导航改变位置的操作；导航、弹窗、窗口切换、滚动或布局改变后使旧坐标失效。等待页面稳定并重新观察，再决定后续动作；不要把滚动和基于旧截图的点击连成一组。
- 区分页面滚动与编辑器内部滚动；Home/End 等按键必须先确认焦点。重复无效时更换定位方式，不反复发送同一按键。
- 输入前确认题号和目标控件，输入后通过控件值、页面文字或最新截图读回。选择题确认实际选中标记及选项文字；代码确认完整头文件、main 和末尾内容。若无法可靠核实，先恢复可观察状态。
- 发现焦点变化、点击未生效或输入落错位置时，先停止输入、恢复目标窗口并检查实际状态，再继续。不要反复盲点，也不要把焦点变化直接归因于用户操作。
- 提交后若结果暂未出现，先观察和核实状态，再决定是否重试。

## 导入其他 Agent

复制整个 coursework-study 文件夹，保留相对目录结构。

- 支持 SKILL.md 的工具：放入该工具指定的技能目录并按其机制启用。
- 支持自定义指令或项目规则的工具：将 SKILL.md 作为入口指令，并让 Agent 能按相对路径读取 references。
- 只能读取附件的工具：提供入口文件与本次任务需要的引用文件，明确要求遵循这些指令。

使用提示：

> 读取 coursework-study/SKILL.md 及其所需引用，完成我指定的网站、课程与作业，并核实提交结果。

Codex 的 agents/openai.yaml 只提供展示信息，其他工具可忽略。迁移后重新确认浏览器配置、输出目录、可用工具及工具权限；不同工具的自动发现方式不保证一致。
