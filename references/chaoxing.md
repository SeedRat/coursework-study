# 学习通适配经验

这些是已有实测经验，使用时现场核实；不依赖固定坐标或历史带签名链接。

1. 在用户现有 Edge 配置中访问 https://i.chaoxing.com/ 。曾成功识别已有会话进入个人空间；是否仍有效以当前页面为准。
2. 个人空间 → 课程 → 搜索目标课程 → 进入课程 → 作业 → 核对目标标题。
3. 编程题可能提供 C 编辑器、运行按钮及 Accepted 反馈。完整查看模板与输出要求，运行通过后仍需作业页提交及确认。尽可能读取编辑器原始文本，核对全角/半角标点、空格和换行；模板与示例冲突时记录具体差异，依据评测反馈修正，不盲试格式。
4. 提交后可能显示分数、提交时间、查看详情及重做入口，读取实际结果后处理。非满分时检查详情和作业入口是否提供重做；没有入口时报告“未发现重做入口”，不构造内部链接或假设可重做。
5. 部分编辑器限制粘贴。使用工具支持的逐字输入并检查内容；中文输入法可能改变 ASCII 代码，必要时使用可靠的 Unicode 键盘输入方式。
6. 桌面操作遵循工具与移植文件中的稳定性规则，每组操作前激活并核实浏览器；确认缩放与截图坐标一致。Windows 高 DPI 环境中截图与点击坐标可能不同，需按实际控制工具处理。
7. 学习通首页快捷方式和个人空间入口可能进入不同页面，按当前会话和用户目标选择。出现登录或安全验证时遵循所在 Agent 的工具规则，需要用户操作则保留进度并说明。

批量操作时用作业列表确认剩余项目，详情页核实各份成绩或待批阅状态；列表进度包含历史作业，不将总进度说成本轮提交数量。只读复制页面文字后检查来源范围，避免把浮层内容当作题目。

验收示例：若题目要求分别用公式和循环计算 1+2+…+100，应按当前模板实现两种方法并核对结果 5050，再检查当前代码的评测反馈及作业提交结果。此处仅说明验收方式，不声明任何历史作业已提交或获得成绩，不能替代读取当前题目和平台状态。
