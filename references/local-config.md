# 运行环境配置

首次使用时按当前机器和用户需求确定以下配置，用户当次指定优先。

- 浏览器：用户指定的浏览器和现有配置，启动后现场核实会话。
- 网页工具：优先检查 Playwright MCP 是否可用，记录本次连接方式与目标标签页；未连接时使用已有后备工具，不保存连接令牌或会话凭据。
- Skill 目录：当前 Agent 安装本 Skill 的位置。
- 工作目录：Agent 可访问的私有任务目录，用于必要的进度记录、源码和截图。
- 作业子目录：<工作目录>/<平台>/<课程>/<作业名称>，替换不合法字符，重名时添加日期或编号。
- 交付文件：按题目要求制作源码、流程图、运行截图及其他提交附件。

迁移后重新确认工具能力、浏览器、编译器和目录。配置不保存凭据、密码或会话令牌；工作文件不纳入公开仓库。
