# 按题目要求处理

| 题型 | 方法与检查 |
|---|---|
| 选择、判断、填空 | 保持题号对应，独立推导答案，核对单位、精度和多选要求 |
| 计算、证明、简答 | 提供题目需要的过程、条件、结论及格式，必要时做代入或独立计算检查 |
| 编程 | 读取模板、语言及输入输出要求；写最小必要实现，用有意义的边界和正常样例或平台评测验证 |
| 根据代码画流程图 | 根据实际代码绘制开始/结束、处理、输入输出、判断及分支；检查循环回边、条件方向、函数与出口；保留源图并导出要求的图片 |
| 程序截图 | 在指定或可用环境实际运行，保证要求的代码、输入、输出或软件界面可读，再截图 |
| 文档或图片附件 | 按格式、文件大小、数量、命名等要求生成，检查预览后上传 |
| 手绘、实物或实验 | 根据题目准备参考与说明；需要真实手绘、实物或实验素材时由用户提供对应材料，再检查和继续提交 |

流程图可采用 SVG 等易修改形式，按平台要求导出 PNG/JPEG。输入输出通常用平行四边形，处理用矩形，判断用菱形，开始与结束用椭圆，判断出口标注是/否或实际条件值。题目有指定规范时优先按其要求。

页面、图片或公式无法完整辨认时，先展开、滚动或放大检查，必要时询问缺失内容；不要基于被截断的题目决定答案。
